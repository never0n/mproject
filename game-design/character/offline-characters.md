# Offline Characters

-   **\[CANON\]** После выхода персонаж некоторое время остаётся под
    управлением настраиваемого offline-бота.
-   **\[CANON\]** Бот допускает широкую настройку поведения, а не только
    выбор одной готовой работы. Настройка не безгранична: полностью
    автоматизировать весь игровой цикл через бота нельзя.
-   **\[DEFERRED\]** Конкретные возможности и ограничения настройки
    определяются по мере разработки и наблюдения за работой бота в игре.
    На этапе планирования подробный набор правил не фиксируется.
-   **\[CANON\]** Бот может работать, торговать, охранять, возвращаться
    домой и т. п.
-   **\[CANON\]** Offline-персонаж физически уязвим: его можно
    атаковать, похитить, связать, убить.
-   **\[CANON\]** Связанный offline-персонаж ничего не делает; после
    развязывания бот активируется.
-   **\[CANON\]** Через длительное отсутствие offline-бот выключается,
    персонаж исчезает; при входе появляется там же.
-   **\[CANON\]** На аккаунте может быть несколько персонажей, но играть
    можно одним.
-   **\[CANON\]** Аккаунты платные. Один человек может использовать
    несколько аккаунтов одновременно, в том числе ради нескольких
    работающих offline-ботов. Ограничения на активного персонажа и бота
    действуют отдельно внутри каждого аккаунта.
-   **\[CANON\]** Offline-бот работает только у последнего персонажа,
    которым вышли.
-   **\[CANON\]** Прямой передачи имущества между своими персонажами
    нет; через других игроков --- возможно.
-   **\[DEFERRED\]** Точный срок работы offline-бота --- параметр
    последующей балансировки, не вопрос текущего design-интервью.
