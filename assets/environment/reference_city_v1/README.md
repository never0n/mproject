# Объекты из референсного листа — версия 1

20 стилизованных моделей, последовательно построенных в Blender 4.0.2 по
`reference_sheet.png`. Персонажей, животных и человекоподобных статуй нет.
Герб — рельефная геометрия по золотому рисунку на исходном листе.

## Открыть в Blender

- `reference_city_library.blend` — полный набор в порядке листа, 5 столбцов × 4 ряда.
- `blend/01_gatehouse.blend` … `blend/20_cobblestone_patch.blend` — отдельные модели
  с материалами, камерой и освещением. Их можно открывать напрямую и редактировать
  геометрию в Edit Mode.
- В общем файле в переключателе Scene также доступны отдельные сцены `01_…`–`20_…`.
- Коллекции отмечены как assets; их можно добавлять в другой файл через
  File → Append → Collection.

В общем обзоре стоят масштабированные экземпляры коллекций, чтобы все объекты
читались в одинаковых ячейках. **Исходные модели в отдельных сценах и файлах
имеют масштаб в метрах**, Z направлена вверх, лицевая сторона — к −Y.
Размеры каждого объекта записаны в `manifest.json`.

## Экспорт и просмотр

- `glb/` — отдельные модели GLB, с применёнными фасками и материалами.
- `previews/` — PNG каждого объекта и общий вид `00_full_library.png`.
- `manifest.json` — нумерация, размеры, геометрия и пути к файлам.
- `validation.json` — результаты проверки экспортированных GLB.
- `native_validation.json` — проверка повторного открытия всех 20 файлов Blender.

В `.blend` сохранены процедурные материалы дерева, камня, ткани и кровли.
В GLB передаются геометрия, базовые цвета, metallic, roughness и свечение;
процедурная фактура Blender в текстуры не запекалась. Модели не подключены
к игровой сцене автоматически.

## Уровень детализации

Это стилизованная геометрическая реконструкция по одному изображению.
Пропорции и основные элементы повторяют лист, невидимые стороны достроены;
микродетали оригинального рендера упрощены. Вода и огонь — статичная геометрия
с материалами; физической симуляции нет. Листва и ткань имеют тонкие поверхности.
UV-развёртка, LOD и коллизии для игрового движка не создавались.

## Воспроизведение

Из корня проекта, в отдельном процессе Blender:

```sh
blender --background --factory-startup --python tools/build_reference_city.py
blender --background --factory-startup --python tools/package_reference_blends.py
blender --background assets/environment/reference_city_v1/reference_city_library.blend --python tools/render_reference_city.py
```

Генератор использует фиксированные случайные seeds. `heraldry_geometry.json`
содержит геометрию золотого рисунка, извлечённую из локального референса.
Внешние библиотеки 3D и сервисы генерации не использовались.

Экспортёр glTF требует NumPy в Python Blender. В установленном здесь Blender
он доступен через существующий локальный runtime:

```sh
PYTHONPATH=/home/never0n/.cache/uv/archive-v0/an_52MqJxInRLYwU blender --background --factory-startup --python-use-system-env assets/environment/reference_city_v1/reference_city_library.blend --python tools/render_reference_city.py
```
