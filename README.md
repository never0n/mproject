# Мортаун

Для продолжения разработки в Cursor: [карта кодовой базы и передача контекста](docs/CURSOR_HANDOFF.md).

Прототип MMORPG на Rust и Bevy. Версия 55: админка //admin, пять ролей, спавн и управление выбранными целями; команды чата из MasterPrompt, личные сообщения, настройки и серверные роли администрации; материалы камня, штукатурки, дерева, черепицы и мощения с масштабом в метрах; одежда городских жителей по профессиям, рабочие инструменты и движения с паузой на разговор; боевые движения героя и других игроков по типам оружия, движущаяся тетива, вылет стрел и магии; боевые движения и падение противников; модели разбойника, мародёра и отступника с разной одеждой и снаряжением; магазин с осмотром и отдельными кнопками покупки/продажи; именованные NPC с услугами в торговых рядах, доме гильдий, соборе и ратуше. Базовый набор из десяти типов оружия первого уровня с моделями, иконками и хватом; внешние различия рас и полов, предпросмотр героя и видимая экипировка. Есть три ремесленные профессии с опытом и специализацией, цепочка заданий торговца, новые враги и рецепты оружия. Доступны аккаунты и 12 персонажей, серверный бой и добыча, инвентарь с иконками и панель F1–F12, торговля, почта, чат, группы и альянсы с общим складом. Подробности последних изменений — в конце файла.
**Локальная сетевая версия: несколько игроков, регистрация и серверное перемещение. Доступны разбойники, автоатака, навыки и награды за победы.**
Согласованное направление: [описание проекта](docs/PROJECT_DIRECTION.md).
Админка: `//admin`. [Управление, роли и спавн](docs/ADMIN_PANEL.md).
Команды: `/help` для игрока, `//help` для администрации. [Синтаксис, роли и ID](docs/CHAT_COMMANDS.md).

## Обновлённый интерфейс

Тёмная сталь, тонкая латунная окантовка и шрифт с засечками в заголовках.
Панель героя стала компактнее: портрет реальной модели, имя, уровень,
ресурсы и опыт. Чат закреплён слева внизу, панель F1–F12 — по центру,
меню-шестерёнка — справа. Большие окна получили непрозрачный фон и кнопку ×;
окна можно перемещать за заголовок. Escape закрывает окно, не игру.

В инвентаре слева модель и экипировка, справа сетка из 30 ячеек на страницу.
Изученные навыки остаются иконками с описанием при наведении. Обновлены рамки
и фоны 26 иконок. Характеристики разделены на физические и магические показатели,
значения выровнены. Экран входа выделяет выбранное поле и основное действие.
Интерфейс подстраивается под размер окна; попадание мышью, подсказки и
перетаскивание учитывают масштаб UI и плотность экрана.

Для этой работы пользователь разрешил запуск игры и тестов.
Результаты и воспроизводимые команды: [проверка интерфейса](docs/VERIFICATION.md).

## Запуск

На настроенном компьютере всё запускается одной командой из папки проекта:

```sh
./start.sh
```

Скрипт запускает PostgreSQL, собирает актуальную версию, запускает сервер (или
использует уже работающий локальный сервер) и открывает клиент. Для Docker может
потребоваться пароль администратора. После закрытия игры сервер и база остаются
работать. Логи новых процессов: `.local/logs/server.log` и `.local/logs/client.log`.
После обновления сборки скрипт автоматически завершает старый сервер этой папки
с сохранением персонажей и запускает новый.

Ручной запуск и установка зависимостей:

Требуется Rust 1.90 или новее и графический драйвер с Vulkan (Linux) / DX12 или Vulkan (Windows).
Закреплена Bevy 0.18.1, совместимая с установленным при разработке Rust 1.94.1.
Версии зависимостей сохранены в Cargo.lock. Модель и текстуры входят в `assets/characters/adventurer.glb`. При распространении помещайте папку `assets` рядом с исполняемым файлом.
DejaVu Sans встроен в бинарный файл, DejaVu Serif для заголовков поставляется
в assets/fonts. Условия распространения находятся
в `assets/fonts/LICENSE-DejaVu.txt` и должны сопровождать распространяемую сборку.

Из корня проекта запустите базу и сервер:

```sh
docker compose up -d --wait db
cargo run -p mortown-server --locked
```

В другом терминале откройте клиент (можно несколько экземпляров):

```sh
cargo run -p mortown-client --locked
```

На экране входа нажмите «Регистрация» и укажите только логин и пароль.
После регистрации войдите в аккаунт: появится список созданных персонажей (до 12 на аккаунт).
Для нового героя откройте маленькую кнопку «Меню» → «Создать нового персонажа», задайте имя, расу, класс и пол.
Новый герой появится в списке; выберите его и нажмите «Войти».

**Shift+F10 в мире** сохраняет героя и возвращает к выбору персонажей без повторного входа.
«Меню» → «Выйти из аккаунта» возвращает к форме логина. Одновременно подключён один сеанс
на аккаунт. Старые персонажи сохраняются в первом слоте после автоматической миграции.
Осмотр без аккаунта доступен командой `./target/debug/mortown-client --view street`; на экране входа эта кнопка убрана.
Регистрация аккаунтов пока находится в клиенте; её перенос на сайт/апдейтер — отдельный будущий этап.

PostgreSQL слушает только `127.0.0.1:55432`, сервер — `127.0.0.1:3000`.
Пароль базы в compose — только для локальной разработки. Если Docker требует
административного доступа, запускайте `sudo docker compose ...`.
Позиция сохраняется каждые 5 секунд и при выходе; после аварийного завершения
может потеряться движение за последние 5 секунд. Том `mortown_mortown_pg`
сохраняется между перезапусками. `docker compose down` останавливает базу;
не добавляйте `-v`, если хотите сохранить персонажей.

Подробности протокола, проверки и ограничения: [сетевая версия](docs/NETWORK.md).

Первая сборка компилирует движок и может занять несколько минут.
После сборки можно запускать `target/debug/mortown-client`
или `target/debug/mortown-client.exe` на соответствующей ОС.

Для Ubuntu / Linux Mint системные пакеты, если их ещё нет:

```sh
sudo apt-get install build-essential pkg-config libwayland-dev libxkbcommon-dev libx11-dev libxcursor-dev libxi-dev libxrandr-dev libvulkan-dev
```

Для Windows: Rust с инструментальной цепочкой MSVC и Visual Studio Build Tools
с компонентом Desktop development with C++. Собирать той же командой Cargo.
В `.github/workflows/build.yml` предусмотрена сборка для Linux и Windows;
workflow начнёт работать после размещения проекта на GitHub. Сам по себе этот
файл не означает, что сборка Windows уже проверена.

## Управление

- **WASD** — движение относительно камеры; отменяет маршрут кликом.
- **ЛКМ по земле** — построить путь к точке, обходя препятствия.
- **ПКМ + мышь** — вращать камеру.
- **Колесо** — приблизить / отдалить, диапазон 4–2200 метров.
- **F** — переключиться между обзором города и ближней камерой.
- **Бег по умолчанию** — 10 м/с; **Shift** — шаг, 5 м/с.
- **Home** — вернуть стандартное положение камеры.
- **G** — маршрут к ближайшему живому разбойнику за южными воротами.
- **1** — «Мощная атака» воина / «Фаербол» мага; 5 выносливости / маны, перезарядка 2 секунды.
- **Tab** или ЛКМ по врагу — выбрать цель; **Space** — включить/остановить автоатаку.
- **R** — возродиться на площади спустя 10 секунд после смерти.
- **I** или кнопка «Инвентарь» — вещи, снаряжение и кнопка «Ремесло».
- **C** или кнопка «О персонаже» — окно характеристик; **C / Esc** закрывают окно.
- **Shift+F10** — сохранить героя и вернуться к выбору персонажей.
- **Esc** — закрыть окно.

Старт — на неровной в плане центральной площади, около кристального фонтана.
Ратуша-крепость стоит в северном квартале, собор — на северо-западе,
рынок — в восточном квартале, дом гильдий — на юго-западе. К входам
ведут ответвления извилистых улиц; у каждого входа есть шесть невысоких ступеней и пологий боковой пандус.
Внутри этих четырёх зданий крыша скрывается, чтобы можно было осмотреть помещения.
Бронзовые фигуры показывают места для будущих NPC; они пока не интерактивны.
Все 29 жилых корпуса доступны: открытые дверные проёмы, полы, мебель и скрытие крыши при входе. Из города можно выйти через любые из четырёх ворот.

## Что реализовано

- Долина около 12 км в поперечнике: холмы, река и рощи; по периметру замкнутая цепь горных массивов.
- Техническая область 16 × 16 км, отрисовка 18,4 × 18,4 км; проход перекрывается на горных склонах задолго до края сетки.
- Город с локальными возвышенностями 2–5 м, холмом ратуши около 6 м и общим перепадом около 9 м; здания стоят на подготовленных ровных участках без высоких цоколей.
- Нерегулярный крепостной периметр примерно 0,83 × 0,75 км с четырьмя воротами.
- Разветвлённые криволинейные улицы; дома ориентированы к дорогам, без квартальной сетки.
- 29 крупных каменных корпуса: арочные окна на четырёх фасадах, пояса, пилоны и башенки.
- Брусчатка — материал самого рельефа; отрисовка и движение используют одни и те же треугольники.
- Лестницы только у общественных входов: 24 ступени по 20 см, широкие площадки и четыре пандуса.
- Круглые башни, конические шпили, стрельчатые порталы, контрфорсы и знамёна.
- Четыре общественных здания с проходными интерьерами и местами для будущих NPC.
- Персонаж человеческого масштаба, следование рельефу, точная проверка пересечений с повёрнутыми зданиями, стенами и стволами деревьев.
- Асинхронный поиск пути A*; одинаковая проверка проходимости для клика и WASD.
- Камера с проверкой препятствий и земли, дальний обзор и скрытие мелких деталей.
- Русский интерфейс с координатами, расстоянием камеры и пройденным путём.

## Структура и проверки

- `crates/world` — рельеф, планировка, препятствия и навигация без зависимости от Bevy.
  Этот код используется и клиентом, и сервером для одинаковой геометрии препятствий.
- `crates/client` — отрисовка, управление, камера, меню и сетевое соединение.
- `crates/protocol` — протокол, игровые типы и стартовые характеристики.
- `crates/server` — Axum, серверная симуляция Bevy ECS, SQLx и миграции PostgreSQL.

```sh
cargo test --workspace --locked
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked
```

Воспроизводимый снимок для визуальной проверки (папку `artifacts` создать заранее):

```sh
cargo run -p mortown-client --locked -- --view overview --capture artifacts/overview.png --exit-after 180
```

Также доступны `--view interior`, `--view forest`, `--view street` (верхняя улица)
`--view hero` (персонаж), `--view run` (проверка бега), `--view house` (жилой интерьер), `--view stairs` (вход в рынок), `--view region` (долина), `--view mountains` (предгорья), `--view bridge` (мост)
и `--view skyline` (силуэт города с юга); без `--view` запускается
меню входа. Снимок запрашивается на сотом кадре. Эти параметры
предназначены для автономной проверки. Для сетевого теста можно задать переменные автоматического входа (см. NETWORK.md).

Алхимия пропущена по просьбе пользователя. Добавлены видимая экипировка
и варианты внешности рас/полов на текущем скелете. Далее — NPC в зданиях,
замена временных моделей и дальнейшая художественная доработка персонажей. Текущий порядок зафиксирован в

Результаты боя, награды и изменения вещей рассчитывает и сохраняет сервер.

Полное дерево навыков и финальная графика пока не добавлены. Стволы деревьев имеют столкновения. Вода непроходима; плавание пока не реализовано, восточная дорога пересекает реку по каменному мосту.
Участки реки, скрытые поднявшимся берегом, не создают невидимого барьера.
Рельеф имеет согласованные сетки 2/4/16 м со сшитыми границами; полноценная потоковая
загрузка и динамический LOD остаются следующими этапами оптимизации.

Архитектурное направление и источники вдохновения: [город на холмах](docs/ART_DIRECTION.md).

Персонаж: текстурированный средневековый воин с анимациями ожидания, ходьбы и бега. [Авторы и лицензия модели](assets/characters/ATTRIBUTION.md).

## Награды и уровни

Победа над тестовым разбойником приносит 25 опыта и 12 монет персонажу,
нанёсшему последний удар. Четыре победы с нулевого опыта дают второй уровень.
Награда видна в журнале, опыт и монеты — на панели персонажа.
Пороги уровней, рост характеристик, SP и очки характеристик перенесены из старого
проекта. При повышении уровня восстанавливаются здоровье, мана и выносливость.
Награды сохраняются до отправки результата игроку; повторный вход и экипировка
не дублируют бонусы. Монеты и предметы начисляются напрямую победителю.

## Предметная добыча

Разбойник всегда оставляет обрывок ткани, с вероятностью 30% — железный меч
(воину) или резной посох (магу), с вероятностью 20% — усиленную кожаную кирасу.
Оружие даёт +10 атаки, кираса +7 физической защиты. Это тестовый баланс лагеря.
Откройте рюкзак клавишей I: повторные предметы показываются одной строкой
с количеством; снаряжение можно надеть, ткань остаётся материалом. Один вид
снаряжения даёт бонус только от одного надетого экземпляра. Добычу можно продавать у площади или использовать в ремесле.

## Лавка у площади

**T** — маршрут к торговцу; рядом повторное T открывает лавку. Ткань продаётся
за 2 монеты, найденное оружие за 8, усиленная кираса за 6. Продаётся одна копия.
Последний надетый экземпляр сначала нужно снять; стартовый набор не продаётся.
Малое зелье здоровья стоит 15 монет и лечит до 50 HP. **H** или нажатие на зелье
в рюкзаке — выпить. При полном здоровье и после смерти зелье не расходуется.
Торговля доступна в пределах 6 м от торговца при свободном проходе к нему.
Покупка, продажа и использование сохраняются сразу. У торговца пока временная
модель приключенца; ассортимент и цены тестовые.

## Поручения торговца

Подойдите к торговцу у центральной площади и нажмите на него. Приём задания
и получение награды находятся в диалоге. Из лавки можно вернуться к нему кнопкой
«Поручения торговца». **J** открывает журнал с условиями, наградами и прогрессом;
завершённые задания остаются на отдельной вкладке. Следующее поручение появляется
после сдачи предыдущего. Подробности цепочки — в разделе версии 41 ниже.

## Улучшение стартового навыка

**K** открывает развитие «Мощной атаки» или «Фаербола». Ранг 2 требует
уровень 2 и 5 SP; ранг 3 — уровень 3 и 7 SP. SP выдаются при повышении уровня.
Воин: 120% → 140% → 160% физической атаки. Маг: 110% → 130% → 150% магической.
Стоимость применения остаётся 5 ресурса, перезарядка 2 секунды; клавиша атаки — 1.
Ранги изучаются последовательно и сохраняются отдельно для каждого персонажа.
Новые ранги — тестовый баланс прототипа; это ещё не полное дерево способностей.

## Второй навык: замедление

В окне **K** можно изучить вторую способность за 7 SP с уровня 3.
Воин получает «Подрезать сухожилия» (110% физической атаки, 3 м),
маг — «Ледяную стрелу» (120% магической атаки, 12 м).
**2** применяет её к выбранной цели: расход 8 ресурса, перезарядка 8 с.
При попадании скорость врага падает на 40% на 4 с. Замедленный противник
подсвечен голубым, остаток эффекта виден возле его HP. Промах расходует ресурс,
но не замедляет. Коэффициенты — тестовый баланс; анимации удара и снаряда пока нет.

В окне **C** кнопки «+1» распределяют свободные очки между шестью характеристиками.
Очки выдаются каждые 6 уровней (на уровнях, кратных 12, — два). Сервер
пересчитывает боевые показатели и ресурсы с учётом уровня и экипировки.

## Инвентарь и панель действий

- **I** — сетка предметов и трёхмерная модель героя слева. Характеристики,
  класс, количество, применение и цена предмета появляются при наведении.
- Каждая копия оружия и доспеха занимает отдельную клетку; зелья и материалы
  складываются в стопки. Надетый экземпляр находится только в слоте экипировки.
- Перетащите вещь на модель/подходящий слот, чтобы надеть. При замене старая
  вещь возвращается в освободившуюся ячейку. Снятие — перетаскиванием в рюкзак.
- Вещи можно переставлять по любым ячейкам; занятые ячейки меняются местами.
  Стрелки над сеткой и **PageUp/PageDown** переключают страницы по 30 клеток.
- **K** — только изученные навыки. Их урон, расход, дальность, перезарядка,
  эффекты и требования следующего ранга видны при наведении. Кнопка «Развитие» открывает обучение и улучшение; доступные действия
  появляются, когда выполнены требования уровня и SP. Основной вид — только сетка иконок.
- Панель **F1–F12** не заполняется автоматически. Перенос из рюкзака/навыков
  создаёт ярлык; перенос внутри панели перемещает его или меняет два местами.
  Перенос предмета с панели в рюкзак очищает ярлык и ставит вещь в выбранную клетку.
- Отсутствующие предметы и неизученные навыки на панели не показываются.
  Существующие пользовательские привязки сохраняются. **ПКМ** очищает ячейку.
- Клавиша F1–F12 или щелчок применяет действие при закрытых окнах.
  Расположение рюкзака, панели и выбранная копия экипировки сохраняются на сервере.
- **Shift+F10** — выбор персонажа; **Ctrl+Shift+F12** — снимок в режиме `--capture`.

Модель показывает героя с анимацией ожидания. Внешний вид пока общий:
смена предметов меняет характеристики и слоты, но не одежду самой 3D-модели.

## Первое ремесло (24)

В лавке у площади [T] продаётся рецепт усиленной кожаной кирасы за 25 монет.
Каждый разбойник теперь оставляет кусок кожи и обрывок ткани.
Для одной кирасы нужны 6 кусков кожи и 4 обрывка ткани.
В инвентаре [I] нажмите «Ремесло»: видны только принадлежащие герою рецепты,
счётчики материалов и результат; характеристики доступны при наведении.
Кнопка изготовления появляется, когда все материалы собраны.

Рецепт остаётся, ингредиенты расходуются, новая кираса (+7 физической защиты)
появляется отдельной ячейкой в рюкзаке. Можно закрепить рецепт на F1–F12:
его активация создаёт одну вещь по тем же правилам. Дополнительная плата
и станок не требуются. Сервер сохраняет результат вместе с расходом материалов.
Это первый рецепт прототипа; профессии, качество и очереди изготовления ещё не добавлены.

## Новые навыки из документа (25)

- Уровень 2, 3 SP: воин — «Разрыв аорты» (кровотечение усиливается от движения);
  маг — «Призма хаоса» (огонь, лёд или яд).
- Уровень 3, 4 SP: воин — «Костолом» (реже атаки врага);
  маг — «Зыбучий песок» (область радиусом 4 м на 6 секунд, замедление и промахи).
- Уровень 4, 5 SP: воин — «Грязный приём» (ослепление на 1,5 секунды);
  маг — «Перегрузка» (260% магической атаки и блокировка навыков на 10 секунд).

Откройте K → «Развитие». Кнопки изучения показываются при достаточном уровне
и количестве SP. Наведите на название для описания до изучения. После изучения
навык появится иконкой; перетащите его на свободный F1–F12 и применяйте по
выбранному врагу. Первые две способности и их прежние привязки сохраняются.
Длительности эффектов видны у выбранной цели, песок обозначен областью на земле.

По просьбе пользователя в этой итерации выполнена только сборка:

и баланса пользователь выполняет самостоятельно после перезапуска через ./start.sh.

## Расовые навыки и торговля (26)

Продолжение идей из документа: каждому герою доступна одна расовая способность.
Изучение — уровень 2, 3 SP, через K → «Развитие».

- Люди и дварфы: «Дымовая завеса» — на 4 секунды снижает вероятность попадания
  по герою на 80%. Цель не нужна; движение и атаки остаются доступны.
  Расход 10 маны/выносливости, перезарядка 20 секунд.
- Золотые и лесные эльфы, полуорки: «Гнев земли» — 70% атаки по врагам
  в радиусе 4 м от выбранной цели; при попадании оглушает на 1,5 секунды.
  Дальность 12 м, расход 12, перезарядка 16 секунд.
- Полумутанты: «Кислотный плевок» — 50% атаки; при попадании физическая защита
  цели обнуляется на 5 секунд. Дальность 8 м, расход 8, перезарядка 12 секунд.
  Магическую защиту и периодический урон эффект не меняет.

Расовые навыки перетаскиваются из K на F1–F12. Используемый ресурс и тип прямого
урона зависят от класса: выносливость/физический урон у воина, мана/магический у мага.
Выбор расовых групп взят из тематических групп документа; значения — баланс прототипа.

«Торгаш» доступен всем расам и классам со второго уровня за 5 SP. После изучения
постоянно снижает цену покупки на 10% с округлением вверх до целой монеты:
зелье 15 → 14, рецепт кирасы 25 → 23. Продажные цены не меняются. Иконка
отображается в K, информация — по наведению; закреплять пассивный навык на
панели не требуется. Лавка и подсказки показывают итоговую цену.

Сборка обновлена в этой папке. Закройте прежний клиент и запустите ./start.sh,
чтобы загрузить новый клиент и автоматически обновить локальный сервер.
По просьбе пользователя тесты, Clippy и игровой прогон не выполнялись.

## Почта персонажей (27)

Откройте **M** или кнопку «Почта» слева. «Написать» открывает поля имени
получателя, темы и текста. **Tab** переключает поля, **Enter** в тексте
добавляет строку, **Ctrl+Enter** отправляет письмо. Поддерживаются русские буквы,
стрелки влево/вправо, Home/End, Backspace/Delete и прокрутка длинного письма.
Тема — до 128 символов, текст — до 1024. Отправка доступна по имени персонажа,
в том числе другому герою своего аккаунта; получатель может быть вне игры.

Папки «Входящие» и «Отправленные» показывают письма страницами. Нажатие открывает
полный текст; есть ответ и удаление своей копии. Новые письма отмечены точкой,
счётчик на кнопке обновляется каждые пять секунд. Удаление у отправителя
не удаляет письмо у получателя. Даты указаны в UTC.

**Esc** закрывает окно, сохраняя черновик на время текущего входа персонажем.
Во время письма игровые горячие клавиши и перемещение заблокированы.
Вложения предметов и наложенный платёж запланированы следующим шагом.

Закройте прежний клиент и запустите **./start.sh** из этой папки:
скрипт обновит сервер, который автоматически создаст таблицу почты.
Сборка подготовлена; тесты, Clippy и запуск игры по вашей просьбе не выполнялись.

## Компактный интерфейс (28)

Шестерёнка справа внизу открывает меню: персонаж, инвентарь, навыки, почта,
ремесло, торговец, действия боя и выбор героя. Пункт «Управление» раскрывает
справку по клавишам. Недоступные действия скрываются; зелье появляется при
наличии в рюкзаке, возрождение — после смерти. Горячие клавиши сохранены.
Кнопка ремесла сразу открывает рецепты, без промежуточного открытия рюкзака.

С основного экрана убраны постоянные подсказки и отдельные кнопки открытия
окон. Показатели героя, местоположение, цель и задание остаются на HUD.
Журнал перенесён в левый нижний угол над панелью F1–F12 и сужен до 320 пикселей.
Полноценный чат пока не реализован. Клики блокируются только в фактических
границах интерфейса; прежние невидимые широкие зоны исключены.

## Окна, цели и инвентарь (29)

Панель персонажа содержит только имя, уровень, опыт, здоровье, выносливость и ману.
Нажатие на неё выбирает себя. Чат (пока системные сообщения) закреплён вплотную
к левому нижнему углу, меню — справа. Пункты маршрута к лагерю, торговца и зелья
убраны из меню. Перетаскивайте окна за тонкую полосу с точками вверху: персонажа,
местоположение, цель, инвентарь, навыки, ремесло, почту, журнал, панель действий,
а также окна входа/выбора персонажей. Положение сохраняется до закрытия клиента.
Чат и меню не перетаскиваются.

**J** или меню → «Задания» открывает журнал. Есть доступные, активные и выполненные
задания, описание, заказчик, место, прогресс и награды. Первое поручение «Безопасная
дорога» принимается и сдаётся у торговца. Постоянный трекер справа удалён.

ЛКМ по существу/игроку выбирает цель; Tab перебирает противников. Вверху появляется
панель с именем и уровнем. У игроков, включая себя, ресурсы скрыты. У разбойников
HP берётся из серверного состояния. Полосы маны и выносливости подготовлены для
NPC с такими ресурсами; у текущих разбойников и мирного торговца эти механики
отсутствуют, поэтому показано «не используется». У торговца также нет боевого HP.
Выбор игрока или мирного торговца прекращает прежнюю автоатаку; атака таких целей
не поддерживается. При выходе цели из мира её панель закрывается.

Монеты и золото отображаются предметами в обычных ячейках инвентаря с разными
иконками. Их можно переставлять; количество связано с серверным балансом, покупки
и награды обновляют его автоматически. Нулевая валюта не занимает ячейку.
Валюту нельзя надеть, удалить или назначить на панель навыков. Баланс не копируется
в независимые предметы: источником истины остаётся серверное значение.
Все надеваемые предметы отображаются отдельными экземплярами, без стопок.
Мечи, посохи, обычная и усиленная броня имеют отдельные иконки; усилены отличия
железного меча, резного посоха и усиленного доспеха.

Собраны клиент и сервер; протокол 19. По просьбе пользователя тесты, Clippy и игра
не запускались. Для обновления закройте старый клиент и выполните ./start.sh.

## Диалоги и выход (30)

Escape больше не завершает игру, в том числе на экране входа. Он закрывает
открытые окна и подменю. Для выхода нажмите шестерёнку → «Выйти из игры»:
клиент ждёт завершения текущей операции и подтверждения сохранения героя,
после чего закрывается. В режиме осмотра выход выполняется сразу.

Подойдите к торговцу на расстояние до 6 метров и нажмите на его модель.
Если между героем и NPC нет препятствия, открывается диалог с приветствием
и кнопками «Открыть магазин» и «До встречи». Приветствие учитывает состояние
поручения торговца. Из диалога магазин открывается без дополнительных клавиш.
Вдали щелчок выбирает NPC и предлагает подойти ближе. При смерти, выходе из мира
или удалении от NPC разговор закрывается. Диалог можно перемещать за верхнюю
полосу и закрывать Escape. Клавиша T и прежняя торговля остаются доступны.

Текущий дружественный NPC в мире — торговец. Реальные покупки и награды
по-прежнему проверяет сервер. Сборка обновлена; тесты и игра не запускались.

## Почтовые вложения (31)

**M → Написать → Вложить вещь**: слева вместо писем появится список вещей рюкзака
с иконками и страницами. Нажмите на нужную вещь. Для материалов, зелий и рецептов
выберите количество кнопками − / + / «Всё»; максимум 9999 за письмо.
Один экземпляр оружия или брони отправляется отдельно. Вложение можно убрать
из черновика до отправки. Надетые вещи и валюты в выборе не показываются.
Тема и текст письма остаются обязательными.

После отправки вещь исчезает из рюкзака и хранится в письме. Получатель открывает
письмо и нажимает «Забрать вложение»: вещь появляется в свободной ячейке либо
добавляется к стопке. Экипировка не надевается автоматически и не складывается.
Почта работает и между разными героями одного аккаунта, в том числе вне игры.
Отправка и получение вещей доступны живым персонажам.

Повтор запроса не списывает и не выдаёт вложение ещё раз. Отправитель может
удалить свою копию письма; получателю сначала нужно забрать вещь. Вложения
не имеют срока истечения. При снятии отдельной копии из рюкзака сохраняются
расположение остальных вещей, надетая копия и её ярлыки; ярлык отправленной копии
очищается. Стартовые вещи также отправляются и не восстанавливаются при входе.

Валюты, платные вложения и возврат отправителю пока не добавлены.
Миграция 0006 создаётся автоматически при следующем запуске сервера через ./start.sh.
Сборка подготовлена; тесты, Clippy, миграция в рабочей БД и игровой прогон
по просьбе пользователя не выполнялись.

## Версия 32 — оплата почтовых вложений

В почте M выберите предмет и укажите цену за всё вложение: 0 — бесплатно,
до 1 000 000 монет. Получатель видит цену и баланс; для платной вещи требуется
отдельное подтверждение оплаты. Без достаточного количества монет выдачи нет.
Оплата сохраняется вместе с выдачей вещи; повторное получение не списывает деньги.
Отправителю в игре монеты зачисляются в течение пяти секунд, вне игры — после
входа персонажем. При превышении предела баланса 4 294 967 295 монет платёж
остаётся на хранении до уменьшения баланса. Возврат незабранных вещей добавлен в версии 33.

Закройте старый клиент и запустите `./start.sh`: скрипт обновит сервер и применит
миграцию 0007. Тесты и игровой запуск по вашей просьбе не выполнялись.

## Версия 33 — возврат почтовых вложений

Откройте письмо в почте M и нажмите «Вернуть вложение отправителю», затем
подтвердите возврат. Получатель может отказаться от вещи, отправитель — отозвать
её из отправленных до получения. Монеты при возврате не списываются.

Вещь приходит исходному отправителю отдельным бесплатным письмом, даже если
он вне игры или удалил свою копию исходного письма. Её нужно забрать в рюкзак.
Исходное вложение после возврата получить нельзя; уже полученное вернуть через
почту нельзя. Повторное подтверждение не создаёт ещё одну вещь. Возвращённые
вложения хранятся до получения, повторный возврат и автоматическое истечение
срока хранения не предусмотрены.

Обновлены клиент и сервер. Закройте старый клиент и запустите `./start.sh`;
миграция 0008 применяется сервером при запуске. Тесты и игра не запускались.

## Версия 34 — торговля между игроками

Выберите другого игрока рядом и нажмите «Предложить обмен» в его панели цели.
Второй игрок принимает приглашение. Каждая сторона выбирает одну вещь (одну
копию экипировки или до 9999 единиц стопки) и/или монеты, затем нажимает
«Предложить». Подтвердите обмен после просмотра обеих сторон. Можно передать
подарок: предложение одной стороны может быть пустым.

Вещи выбираются кнопками предыдущей/следующей вещи из рюкзака, количество —
кнопками количества, монеты — шагами 1/10/100/1000. Иконки показывают подсказки
при наведении. Окно можно перемещать. Надетые вещи не предлагаются.
После подтверждения редактирование закрывается; «Изменить предложение» сначала
снимает подтверждения на сервере. Изменение любого опубликованного предложения
сбрасывает готовность обеих сторон. Вещи до завершения остаются в рюкзаках.

Обмен требует дистанции до 6 метров и прямой видимости, длится до двух минут.
Отмена, выход, смерть или отход участника закрывают его без передачи имущества.
Изменение инвентаря через другие игровые действия отменяет обмен; изменение
добычи дополнительно сверяется при завершении. Два инвентаря и баланса монет
сохраняются одной транзакцией, после чего оба клиента получают актуальное состояние.

Сборка клиента и сервера обновлена. Закройте старый клиент и запустите `./start.sh`.
Протокол 23; новых миграций для обмена нет. Тесты и игру по вашей просьбе не запускал.

## Версия 35 — чат

Чат закреплён в левом нижнем углу, ширина — 300 пикселей. «Общий» доставляет
сообщение всем в мире, «Рядом» — персонажам в радиусе 60 метров на момент
отправки. «Система» содержит прежние игровые уведомления.

Enter открывает ввод, повторное нажатие отправляет сообщение, Escape отменяет
ввод и сохраняет черновик. Во время ввода горячие клавиши игры отключены.
Длина сообщения — до 280 символов. Сообщения прокручиваются колёсиком;
«Последние сообщения» возвращает к новым. Клиент хранит последние 100 сообщений
текущего входа в мир; прежняя история с сервера при входе не загружается.

Нажмите чужое сообщение: доступны «Игнор» и «Пожаловаться». Игнор сохраняется

Жалобы сохраняются в базе для рассмотрения, автоматических наказаний нет.
Сервер допускает до пяти сообщений за 10 секунд, с интервалом не менее секунды;
ограничение общее для персонажей аккаунта и сохраняется при переподключении.

## Версия 36 — группы

60 секунд. До первого принятия группа ещё не создаётся. Лимит — пять игроков,

Лидер отмечен звездой. Он может приглашать, исключать выбранного участника

## Исправление ввода чата

Чат упрощён: вкладки, история и строка ввода. Enter начинает ввод и отправляет
сообщение, Escape возвращает управление игре, сохраняя черновик. После отправки
фокус остаётся в чате. Отдельная кнопка отправки убрана; кнопка перехода к новым
сообщениям появляется только при прокрутке истории.

Во время ввода очищаются также удерживаемые игровые клавиши. Перехваченные
клавиши блокируются до физического отпускания, в том числе после Escape.
Ответ сервера больше не снимает фокус и не возвращает горячие клавиши внезапно.
Обычные окна при начале ввода закрываются; редактор письма сохраняет свой Enter.

## Альянсы (37)

**Меню → Альянс** или **L** открывает перемещаемое окно в новой теме интерфейса.
Название — от 2 до 24 символов. Создание стоит 1000 монет и требует подтверждения;
сумма и начальный лимит 20 участников перенесены из старого проекта.

Лидер и офицеры вводят имя персонажа и отправляют приглашение на две минуты.
Приглашать можно и персонажа вне игры: приглашение сохранится до истечения срока.
Получатель увидит уведомление и сам примет или отклонит приглашение.
Действующие приглашения резервируют свободные места; игнор запрещает приглашения
от заблокированного персонажа. Персонаж состоит максимум в одном альянсе.

В составе видны имя, уровень, роль и присутствие в мире. Выберите участника:
лидер назначает/снимает офицеров, исключает участников и передаёт лидерство;
офицер приглашает и исключает только обычных участников. После передачи прежний
лидер становится офицером. Обычные участники и офицеры могут выйти. Лидер сначала
передаёт полномочия либо распускает альянс. Роспуск удаляет состав и приглашения,
стоимость создания не возвращается. Для выхода, исключения, передачи и роспуска
есть отдельное подтверждение; все права повторно проверяет сервер.

Состав принадлежит персонажу, хранится в PostgreSQL и сохраняется при смене героя,
разрыве соединения и перезапуске сервера. Изменения состава рассылаются подключённым
клиентам; присутствие и срок приглашения обновляются примерно каждые пять секунд.

В чате появляется вкладка «Альянс». Сообщения получают только участники на момент
отправки, без ограничения расстояния. Игнор, жалобы и общий лимит чата действуют.
При смене альянса черновик очищается, сообщения другого альянса скрываются.
Сервер сохраняет сообщения; загрузка истории после повторного входа ещё не добавлена.
Склад добавлен в версии 38. Развитие навыков альянса ещё не реализовано.
Форум из старого проекта исключён из ближайшего плана; сейчас общение идёт через чат.

## Склад альянса (38)

Открывается через **L → Склад альянса** или **Меню → Альянс → Склад альянса**.
Слева рюкзак, справа общий склад: 50 ячеек, по 25 на страницу. Надетые вещи
и валюты в списке вкладов не показываются. Исходные позиции вещей в рюкзаке
сохранены; свободные ячейки остаются свободными.

Выберите вещь, задайте количество кнопками − / + / «Всё» и нажмите «На склад»
или «В рюкзак». Можно перетащить вещь в соседнюю сетку: переносится выбранное
количество, по умолчанию одна штука. Описание — при наведении.
Оружие и броня занимают отдельные ячейки, материалы и расходники объединяются
в стопки до 9999. Положить может любой участник; забрать — лидер и офицеры.
При заполнении всех ячеек можно пополнять существующие неполные стопки.

Кнопка «Журнал» показывает последние восемь перемещений: кто, когда и сколько
положил или забрал. Время указано в UTC. Окно перемещается за заголовок,
кнопка × и Escape закрывают его. Склад доступен участникам через окно альянса,
привязки к отдельному NPC пока нет. Альянс с вещами на складе распустить нельзя.

Склад, личный инвентарь и запись журнала сохраняются одной транзакцией.
Сервер проверяет актуальность склада, членство и права; при чужом изменении
нужно заново выбрать вещь. Активный прямой обмен при переносе отменяется.

Протокол 27, миграция 0012, /health — mortown-38. Клиент и сервер собраны в этой
папке; закройте старый клиент и запустите `./start.sh`. Миграцию применит сервер.
В этой итерации выполнены форматирование и сборка, без запуска игры и тестов.


## Совместные награды группы (39)

Соберите группу через выбранного игрока → «Пригласить в группу». Награда
принадлежит группе персонажа, который добил врага. На момент гибели врага
сервер учитывает живых участников в радиусе **60 м от него**, включая высоту.
Погибшие, находящиеся дальше и вышедшие из группы награду не получают;
они также не уменьшают доли остальных. Участнику рядом не обязательно наносить удар.

За разбойника остаётся один общий набор: **25 опыта, 12 монет**, ткань, кожа
и прежние шансы оружия/доспеха. Опыт и монеты делятся на число получателей,
целочисленный остаток переходит по очереди. Например, два участника получают
13 и 12 опыта, по 6 монет; на следующей победе лишняя единица опыта достаётся другому.
Общего множителя за группу пока нет. Персонаж максимального уровня свою долю
опыта не получает; она не перераспределяется.

Каждая выпавшая вещь передаётся одному участнику по кругу. Очередь продолжается
между победами, пропускает погибших и далёких и не сбрасывается при передаче
лидерства. Выпавшее оружие определяется классом добившего, как в одиночном бою;
тип оружия при передаче другому участнику не меняется. Надевание автоматом
не происходит; одинаковое оружие и броня остаются отдельными экземплярами.

Каждому получателю засчитывается убийство и прогресс принятого задания
«Безопасная дорога». Повышение уровня и восстановление ресурсов работают
как раньше. Одни правила действуют для автоатаки, обоих базовых навыков,
расовых/классовых способностей, массовой атаки, кровотечения, огня и яда.
Без группы персонаж получает обычную полную награду.

Наведите курсор на **i в панели группы**: там правила и список получателей
последней добычи. Личная доля также видна в сообщении награды на вкладке
«Система». Награды сохраняются с прогрессом персонажа прежним механизмом
сохранения после убийства, автосохранения и выхода. В версии 40 группа и очередь
выдачи сохраняются на время переподключения. При роспуске или перезапуске сервера
они сбрасываются.

Протокол 28, /health — mortown-39; новой миграции нет. Клиент и сервер обновлены
для `./start.sh`. Выполнены форматирование и сборка, без запуска игры и тестов.


## Возвращение в группу (40)

После потери связи, закрытия игры или возврата к выбору героев место в группе
сохраняется **на три минуты за тем же персонажем**. Войдите в аккаунт и выберите
этого героя до окончания отсчёта — он вернётся в прежний состав без приглашения.
Другой персонаж аккаунта это место не наследует. Групповой чат снова становится
доступен; сообщения, отправленные за время отсутствия, пока не догружаются.

В составе остаются имя и уровень отсутствующего, отметка «Не в мире» и таймер.
Зарезервированное место учитывается в лимите пяти участников. Пока персонаж
отсутствует, он не участвует в распределении опыта, монет, вещей и квестовом
зачёте. Очередь добычи продолжается для находящихся рядом участников.

Если вышел лидер, лидерство получает следующий участник в игре. Вернувшийся
прежний лидер не забирает полномочия обратно. Если вышли все, состав удерживается
до истечения индивидуальных таймеров; при возвращении первым лидером станет
вернувшийся участник, если текущий лидер ещё отсутствует.

Лидер может выбрать отсутствующего в списке и исключить его, освободив место.
Передача лидерства доступна только участнику в игре. «Выйти из группы» действует
сразу; исключённый, вышедший явно или опоздавший персонаж автоматически не вернётся.
По истечении трёх минут место освобождается даже при отсутствии всех клиентов.

Сервер отправляет Ping каждые пять секунд и прекращает сеанс примерно через
20 секунд без входящих сообщений. После сохранения героя начинается трёхминутный
отсчёт. При очень быстром повторном входе старая сессия ещё может завершаться —
если показано «аккаунт уже подключён», повторите вход спустя несколько секунд.
Ожидание записи в сокет ограничено и у сервера, и у клиента.

Восстановление работает, пока запущен тот же сервер: перезапуск сервера пока
распускает группы. Автоматический вход в аккаунт не добавлен. Протокол 29,
/health — mortown-40, новых миграций нет. Сборка обновлена для `./start.sh`;
игра и тесты в этой итерации не запускались.


## Стартовая цепочка торговца (41)

1. **Безопасная дорога** — победить трёх разбойников после принятия поручения.
   Награда: 75 монет и два малых зелья здоровья. Существующий групповой зачёт
   для живых участников рядом сохраняется.
2. **Запас для каравана** — принести торговцу 4 ткани и 4 кожи из своего рюкзака.

## Новые противники и оружейные рецепты (42)

На южном тракте теперь семь противников. Первые три — прежние разбойники
1 уровня для стартового поручения. Дальше по дороге, примерно в 350 и 440 метрах
от ворот, находятся два **мародёра тракта 3 уровня**. Они медленнее разбойников,
лучше защищены от физических ударов и слабее — от магии. Ещё дальше, за поворотом
дороги у точки [390, 790], стоят два **пепельных отступника 5 уровня**.

Отступник отвечает магическим «Пепельным зарядом» с расстояния до 11 метров.
Подготовка длится 1,2 секунды: в окне цели виден отсчёт, навершие посоха светится.
Оглушение, выход из дальности или потеря прямого прохода к цели прерывают заряд;
при смене цели подготовка также начинается заново. Вблизи он не убегает бесконечно.
Все враги пока вступают в бой в ответ на атаку/враждебное умение, как и прежние
разбойники. После потери цели возвращаются к месту появления; предел погони — 45 м.
Мародёры возвращаются после смерти через 45 секунд, отступники — через минуту.

Мародёр даёт 40 опыта, 18 монет, одну железную заготовку и одну кожу.
Отступник — 60 опыта, 24 монеты, один осколок рунного камня и одну ткань.
Материалы гарантированы. В группе делится один общий набор награды по прежним
правилам; новое существо не умножает добычу по числу участников. «Безопасная
дорога» по-прежнему считает только обычных разбойников, включая групповой зачёт.

В лавке появились два рецепта по 80 монет до скидки «Торгаша»:

- **Стальной меч**: 6 железных заготовок + 3 кожи, физическая атака +16, для воина.
- **Рунный посох**: 6 осколков рунного камня + 3 ткани, магическая атака +16, для мага.

Изготовление доступно через рюкзак → «Ремесло» либо рецепт на панели F1–F12.
Рецепты не расходуются. Вещи можно изготовлять для другого класса, но надеть
оружие может только соответствующий класс. Каждая копия оружия занимает свою
ячейку. Перемещение, экипировка, обмен, почта и склад используют общий каталог.
Торговец покупает новое оружие по 18 монет, новые материалы — по 4 за единицу.

Лавка показывает товары и продажу из рюкзака сеткой иконок. Нажатие покупает или
продаёт одну вещь; характеристики, состав рецепта и цены появляются при наведении.
В ремесле видны только имеющиеся рецепты, их можно переключать иконками; материалы
и результат показываются для выбранного рецепта. Добавлены шесть отдельных иконок
материалов, рецептов и оружия. Израсходованные полностью стопки при изготовлении
очищают свои ярлыки на панели, сохраняя расположение остальных вещей.

Противники получили разные временные силуэты: наплечники, меч и щит у мародёра,
мантия и светящийся при подготовке посох у отступника. Это геометрические модели
прототипа; полноценные модели и анимации остаются в плане визуального наполнения.

## Профессии и ремесленное мастерство (43)

В окне **«Ремесло» → «Профессии»** доступны три независимых направления:
кожевничество (кирасы), кузнечное дело (мечи) и рунопись (посохи). Их можно
развивать одновременно любым классом. Рецепты и общий счётчик старых изготовлений
сохранены. Опыт отдельных профессий начисляется только за новые изделия:
в старых сохранениях нет истории, позволяющей надёжно распределить их по профессиям.

Каждое успешное изготовление даёт 25 опыта своему ремеслу до максимального
5 уровня. Пороговые значения общего опыта: 0 / 50 / 150 / 300 / 500.
Соответственно, уровни 2–5 достигаются после 2, 6, 12 и 20 изделий одного
направления. Боевой опыт, SP и опыт других профессий это не изменяет.
Неудачное изготовление, повтор команды, покупка и получение готовых вещей
ремесленный опыт не дают.

Со 2 уровня можно выбрать это направление **основной специализацией**.
Одновременно действует одна специализация. Первая бесплатна; последующая
смена стоит 100 монет и подтверждается в окне с указанной стоимостью.
У нового направления тоже должен быть минимум 2 уровень. Опыт, уровни
и рецепты всех направлений при смене сохраняются; ремеслом без специализации
можно продолжать заниматься.

Мастерство уменьшает расход материалов:
- Уровни 3 и 5 экономят по одной дополнительной единице вспомогательного
  материала: ткани для кирасы/посоха, кожи для меча.
- Выбранная специализация со 2 уровня экономит одну единицу основного материала:
  кожи, железа или рунных осколков. С 4 уровня экономия увеличивается до двух.
- Расход каждого ингредиента не может стать меньше одной единицы. Смена
  специализации переносит только бонус основного материала; бонус мастерства
  для вспомогательного остаётся у каждого прокачанного направления.

Например, меч требует 6 железа + 3 кожи у новичка; при кузнечной специализации
2 уровня — 5 + 3, а при 5 уровне — 4 + 1. Характеристики результата прежние,
рецепт не расходуется, оружие по-прежнему занимает одну ячейку на каждый экземпляр.
Скидка рассчитывается по уровню **до** изготовления; полученный новый уровень
влияет на следующую вещь.

Вкладка «Рецепты», подсказки и сервер используют один расчёт фактического расхода.
Под рецептом видно текущее ремесло и получаемый опыт, на вкладке «Профессии» —
уровни и полосы опыта. Достаточные материалы остаются зелёными, недостающие —
красными. Изготовление через рецепт на F1–F12 учитывает те же бонусы.

Материалы, результат, счётчик, ремесленный опыт и квестовый зачёт сохраняются
одной транзакцией. Выбор специализации и плата также сохраняются вместе.

Прогресс отдельный у каждого персонажа и загружается при следующем входе.

## Атаки и смерть противников — версия 50

На текущем скелете добавлены отдельные движения: разбойник отводит руку и
делает выпад кинжалом, мародёр поднимает топор и рубит с поворотом корпуса,
отступник готовит заряд и выбрасывает свободную руку вперёд при его выпуске.
Оружие следует кисти, щит остаётся в левой руке. Отменённый замах плавно
переходит обратно в обычную позу. Промах также сопровождается движением.

Момент урона связан с серверным замахом: у разбойника подготовка 0,4 с,
у мародёра 0,6 с. У отступника сохранена прежняя подготовка 1,2 с.
Урон не наносится в начале замаха. Выход из радиуса, препятствие, потеря цели,
оглушение и смерть прерывают подготовку; после прерывания есть пауза перед
новой попыткой. Враг останавливается на время замаха и завершения движения.
Интервал между непрерванными ударами ближнего боя сохранён — 2 и 2,4 с;
первый удар теперь запаздывает на длительность замаха. Формулы попадания,
урона, критов и наград не менялись. Это делает ближний бой более предсказуемым
и позволяет уйти от готовящегося удара.

После смерти враг подгибает колени и падает примерно за 1,15 с. Тело с оружием
остаётся на пять секунд от момента смерти, затем скрывается до возрождения.
Направление падения выбирается среди четырёх с проверкой препятствий;
высота лежащего тела подстраивается по нескольким точкам рельефа. Это заданная
анимация с приближённой посадкой, без физики ragdoll и столкновений отдельных
конечностей. Труп не блокирует проход и не становится отдельным контейнером
добычи. Награда по-прежнему выдаётся сервером сразу при победе.

Сервер передаёт текущую фазу атаки и время после смерти: новый наблюдатель
видит текущую позу, без повторного замаха/падения. При возрождении убирается
поза трупа и возобновляется обычная анимация. Эта итерация касается противников;
боевые движения героя и других игроков по типам оружия остаются следующим этапом.

## Боевые движения героев — версия 51

Собственный герой и другие игроки показывают подтверждённые сервером атаки:
- Мечи — рубящий удар; топоры — диагональный удар сверху; молот — короткий
  тяжёлый удар. Для двуручных меча/топора/дубины заданы отдельные, более
  широкие движения корпуса и оружия с удержанием второй рукой.
- Кинжал и пика — выпады, с разной длиной и хватом. Без оружия — удар рукой.
- Лук — подъём, натяжение тетивы правой рукой, отпускание и вылет стрелы.
  Тетива и стрела отделены от неподвижной геометрии лука; в предпросмотре
  они остаются в спокойном положении. Расходуемые стрелы пока не добавлены.
- Магия — жест свободной руки, нарастающее свечение и летящий заряд;
  дымовая способность использует отдельный жест. Навыки получают более
  выраженное движение корпуса. Пока это общие движения типов действий,
  без отдельного художественного эффекта для каждой способности.

Стоящий герой визуально поворачивается к цели, на ходу сохраняется работа
ног, а корпус разворачивается в ограниченном диапазоне. При смерти, выходе,
смене персонажа или оружия текущая боевая поза сбрасывается. Предпросмотр
в окнах создания/экипировки не проигрывает атаки из мира.

Сервер передаёт недавние подтверждённые действия вместе с оружием, точкой
цели и возрастом события. Промах тоже вызывает движение; отклонённый запрос
ничего не проигрывает. Если навык и автоатака перекрываются, поза навыка имеет
приоритет; события выстрелов сохраняются отдельно. Повторный снимок не
начинает старую атаку заново.

У героя сохранён прежний мгновенный серверный расчёт урона: анимация и полёт
начинаются после подтверждения, поэтому показ контакта/попадания может быть
позже изменения HP. Это визуальная итерация, без нового замаха с отложенным
уроном, расхода боеприпасов или физики снарядов. Позы заданы на текущем скелете;
посадку оружия, темп движений и особенности разных рас нужно осмотреть в игре.
